# Rex Desk MVP

Local AI Agent Desk Web App.

## Stack
- **Frontend**: React, Vite, Tailwind CSS v4, Lucide React
- **Backend**: Node.js, Express, JSON storage
- **Engine**: Pluggable Agent Engine (Echo -> Gemini CLI)

## Quick Start
1. Double-click `start-dev.bat` OR run:
```bash
# Terminal 1 (Backend)
cd backend
npm run dev

# Terminal 2 (Frontend)
cd frontend
npm run dev
```

2. Open [http://localhost:5173](http://localhost:5173) in your browser.
